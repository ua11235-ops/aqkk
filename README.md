# 安全可靠测评结果库

中国信息安全测评中心「安全可靠测评」公告的自动采集与可视化查询页面。

数据来源：<https://www.itsec.gov.cn/aqkkcp/cpgg/>

## 在线访问

开启 GitHub Pages 后：`https://<用户名>.github.io/aqkk/`

## 这个仓库做什么

`collector.py` 每次运行会：

1. 拉取「安全可靠测评」公告列表页，取出全部期号；
2. 逐期解析公告正文，从各附表提取「产品名称 / 送测单位 / 安全可靠等级」，
   并识别类别（CPU、AI 训练推理芯片、打印机主控芯片、操作系统、数据库）
   与细分类型（桌面/服务器操作系统、集中式/分布式数据库），
   同时拆出操作系统名称里的内核版本；
3. 生成 `data.json`（结构化数据）和 `index.html`（查询页面）。

采集失败时**不会覆盖**已有的 `data.json` 与 `index.html`，避免把线上页面刷成空白。

### 单期失败不会丢数据

如果只是某一期公告抓取失败（超时、改版、解析为空），采集器会从上一版 `data.json`
里把该期的公告元信息和产品条目**原样回填**，并在 `data.json` 的 `carriedOver`
中记录沿用了哪几期；真正一条都采不到时才会整体失败并保留旧文件。

`data.json` 里另有两个诊断字段，便于发现官网改版：

| 字段 | 含义 |
|---|---|
| `failures` | 本次抓取失败 / 解析为空的公告期 |
| `unknownTables` | 附表存在但类别关键词认不出来（官网新增了测评对象时会出现在这里） |
| `skippedRows` | 有序号但字段解析不完整的行，需人工核对 |

## 自动更新

`.github/workflows/collect.yml` 每天自动采集一次（UTC 00:17，北京时间 08:17），有新公告就提交数据并重新部署 Pages。
也可以在 Actions 页面手动点 **Run workflow** 立即采集。

采集周期由 workflow 里的 cron 单一决定，`collector.py` 会解析它并注入页面：
页头的「数据更新于」按周期自动计算陈旧阈值（超过 1.5 个周期变黄、4 个周期变灰），
改频率只需要动 cron 一处。

流水线会做一次数据校验，任一条不满足即判定失败、不提交、不部署：

- `collector.py` 退出码非 0；
- 产品记录为空或少于 50 条；
- 某期公告在产品列表里一条记录都没有；
- 与上一版相比产品数减少，或丢了公告期。

推送失败时会先 rebase 重试；若 `data.json` / `index.html` 与远端冲突（都是生成物），
则基于远端最新代码重新采集后再提交。

## 本地运行

```bash
pip install lxml
python collector.py            # 联网采集并生成
python collector.py --offline  # 不联网，用已有 data.json 重新生成页面
```

> 本机网络若需走代理，`git` 用
> `git -c http.sslBackend=openssl -c http.proxy=http://127.0.0.1:7897 ...`
> （Windows 自带 schannel 后端在部分环境下会报 `SEC_E_NO_CREDENTIALS`）。

## 文件说明

| 文件 | 说明 |
|---|---|
| `collector.py` | 采集器，解析官网公告 |
| `template.html` | 页面模板，含 `__DATA__` / `__ANN__` 占位符 |
| `data.json` | 采集结果（公告元信息 + 产品条目） |
| `index.html` | 生成的可直接打开的查询页面 |
| `.github/workflows/collect.yml` | 定时采集与 Pages 部署 |

## 页面功能

- 按类别、细分类型、等级、公告年份/期号、有效期状态筛选
- 关键词搜索（产品名、版本、送测单位）
- 按通过时间、等级、名称排序；分类视图 / 平铺列表两种视图
- 点开任意产品查看详情：送测单位、通过测评时间、有效期至、内核版本、公告原文链接
- 导出当前筛选结果为 CSV

## 关于「通过测评时间」

公告未单列评审日期，只载明「自发布之日起有效期三年」，
因此**通过测评时间取公告发布日期**，有效期至按发布日 +3 年 −1 天推算。
页面会实时显示每条记录的有效期状态（有效 / 180 天内到期 / 已过期）。
